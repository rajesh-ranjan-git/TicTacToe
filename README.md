## Project Overview

Tic Tac Toe is a client-side implementation of the classic two-player game, playable directly in the browser with no backend involved.

## Features

- **Two-Player Gameplay:** Classic X/O turn-based play on a 3x3 grid.
- **Win/Draw Detection:** Automatically detects winning combinations and draw conditions.
- **Sound Effects:** Cool sound effects on moves and game outcomes.

## Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript

## Folder Structure

```bash
TicTacToe/
├── sounds/      # Sound effect audio files
```

## Installation Guide

### Prerequisites

- A modern web browser
- (Optional) A local static server such as VS Code's "Live Server" extension

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/rajesh-ranjan-git/TicTacToe.git
   cd TicTacToe
   ```

2. Open `index.html` directly in your browser, or serve the folder with a local static server:

   ```bash
   npx serve .
   ```

## Usage Instructions

1. Open the page in your browser.
2. Take turns clicking cells to place X or O.
3. The game announces the winner or a draw, with sound effects.
